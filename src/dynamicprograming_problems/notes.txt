Dynamic Programming
-------------------
1. DP is an optimization technique.
2. It is used to solve problems by breaking them
   into subproblems and storing the results to avoid
   redundant computation.
3. Approach
    |- Top Down <=> Memoization  [recursion + store]
    |- Bottom Up <=> Tabulation  [loop + store]

4. Fibonacci Program
    |- Program1: Without DP
    |- Program2: With Memoization
    |- Program3: With Tabulation

5. Pattern Question

Program4: Minimum cost to reach the Nth step
- You have an integer array cost[], where cost[i] represents
  the cost of stepping on the stair.
- You can start at stair 0 or stair 1. from any stair, you can jump either
  one or two steps.
- Find the minimum cost required to reach beyond the last stair.
- Input: cost = {10,15,20}
- output: 15

Program5: Climbing stairs
- A person wants to climb a staircase containing N steps.
- At each move, the person can climb either one or two steps.
- Find the total number of distinct ways to reach the Nth step.
- Input: 5
- Output: 8
    1   1   2   3   5   8

Program6: Maximum money without robbing adjacent houses.
- A thief wants to rob houses arranged in a straight line.
- Each house contains a certain amount of money.
- Thief cannot rob two adjacent houses.
- Find the maximum amount of money that can be collected.
Input: arr = {2,7,9,3,1}
Output: 12

Explain:
    Way-1 [2,9,1] = 12
    Way-2 [7,3]   = 10
 Rob houses containing [2,9,1]

Program-7: Unique Path
- A robot is placed at the top-left corner of a MxN grid.
- It need to reach the bottom-right corner.
- It can move only
    |- Right
    |- Down
- Find the total number of unique paths.
- Input: m=3, n=3

[HW] Program-8: Maximum Knapsack profit
- A bag with a maximum weight capacity W.
- There are N items, Each item has
    |- Weight
    |- Value
- An item can either be selected once or not selected.
- Find the maximum possible value without exceeding the bag capacity.
- Input:
    items
        weights = {1,3,4,5}
        values  = {1,4,5,7}
    Bag
        W = 7
- Output: 9

    Way-2 Likely
    {4,3}
    {5,4} = 9

    Way-1
    {5,1}
    {7,1} = 8
