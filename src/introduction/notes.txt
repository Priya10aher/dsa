Data Structure and Algorithm
----------------------------
1. Data Structure
- It is a way of organizing and storing data.
- so that we can access, modify, search, insert, delete data.

2. Algorithm
- It is a finite sequence of well-defined steps used to solve a
particular problem.

Example:
    Suppose we have marks of 5 students
    int[] marks = {75,82,91,68,88};

    this 'array' is the data structure

    i want to find highest marks
    1. Assume first mark is max.
    2. compare it with the second mark.
    3. if second mark is greater so update the max
    4. continue until the last mark
    5. return max

    These steps are the 'Algorithm'.

In short:
   Data Structure: How we can store/mange data
   Algorithm: What are the steps to solve problem using the data.
